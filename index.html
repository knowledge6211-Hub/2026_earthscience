三、 核心技術與理論學習重點

1. 網頁建置與雲端部署

結合大語言模型（如 Gemini）輔助生成網頁程式碼 (index.html)，並將其部署至 GitHub Pages。透過 GitHub 免費雲端空間建立對外服務的靜態網頁，作為技術文件、程式碼及教案的展示平台。

2. AI 代理與自動化工具應用

  • Google Antigravity IDE：作為可直接操作電腦本機與環境檔案的 AI 代理。能自動生成內容並寫入資料夾，支援檔案編修與視覺化檢視。
  • Google Apps Script (GAS)：串接 Google 表單與試算表。當學生填寫表單繳交期末報告與 Email 後，自動收集資料並同步寄發確認信件。

3. 地球物理震測實驗與原理

  • 折射震測實務：不破壞地表下產生人工震源與佈設地震儀陣列，探測地下層狀結構。
  • 震波傳播特性分析：接收直達波與折射波。當測點距離較遠時，因折射波進入深層高速地層，到達時間早於直達波。
  • 建築共振反應：透過黏土與竹籤物理模擬，實證不同高度建築物在不同頻率震波下的動態反應差異。

4. CLIL 雙語教案開發與提示詞工程

善用國外開源資源（如 IRIS 平台），結合提示詞工程引導 AI 產出適合國小高年級（5~6年級）的雙語教案設計：
